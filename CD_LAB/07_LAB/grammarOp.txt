------------------------------------------------------
ELIMINATE LEFT FACTORING
------------------------------------------------------
If we have:

A → αβ1 | αβ2

We convert to:

A  → α A'
A' → β1 | β2
-------------------------------------------------------
We convert:
------------------------------------------------------
Identifier_list → id
                | id , Identifier_list
                | id [ number ]
                | id [ number ] , Identifier_list
-------------------------------------------------------
To:

Identifier_list → id Identifier_list'

Identifier_list' → [ number ] Identifier_list''
                 | , Identifier_list
                 | ε

Identifier_list'' → , Identifier_list
                  | ε
